# InfluencerAct Landing Page

Responsive brand website with a coral and dark-purple theme, local images and fonts, and interactive creator, service, award and FAQ sections.

## Requirements

Use Node.js 24 LTS and npm. An `.nvmrc` is included for nvm users (`nvm use`).

## Run locally

```sh
npm ci
npm run dev
```

Open the Local URL printed in the terminal (normally http://127.0.0.1:5173). Vite reloads the page when source files change.

## Project structure

```text
InfluencerAct-Landing-Page/
├── index.html                 # HTML entry point and page content
├── src/
│   ├── main.js                # Interactions and stylesheet import
│   └── styles.css             # Responsive styles and animations
├── public/
│   └── assets/                # Images, videos, fonts, and font licenses
├── docs/
│   └── DESIGN-REFERENCES.md    # Design rationale and references
├── package.json               # Development commands and dependencies
├── package-lock.json          # Reproducible dependency versions
├── netlify.toml               # Netlify build and deployment settings
└── dist/                      # Generated production output; ignored by Git
```

Edit `index.html`, `src/`, and `public/`. Assets in `public/assets/` are available at `/assets/`. The page uses plain HTML, CSS, and JavaScript, with Vite handling development and production builds.

## Build and preview

```sh
npm run build
npm run preview
```

The build generates `dist/`, including optimized JavaScript and CSS and copies of public assets. Preview serves this production build at the URL printed in the terminal (normally http://127.0.0.1:4173). If the default port is occupied, Vite prints the next available port.

Do not edit or commit `dist/`; it is regenerated by `npm run build` and excluded from version control.

## Code formatting

```sh
npm run format
npm run format:check
```

## Deploy to Netlify

Import this repository in Netlify. The included `netlify.toml` configures Node.js 24, the build command `npm run build`, and the publish directory `dist`. Netlify installs the dependencies and builds from the tracked source.

For manual deployment, run `npm ci` and `npm run build`, then upload the generated `dist/` directory.

## Enquiry form

- Single-page form with name, business email and phone.
- Budget slider and manual rupee field, starting at a minimum of ₹10,000.
- Multiple social platforms, with an All platforms option.
- Validation prepares an email draft to `contactus@influenceract.com` for the visitor to send. Automatic lead capture requires a form or CRM endpoint.

Font licenses are included under `public/assets/fonts/` and are copied into the production build.
